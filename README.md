# Elnie Android Rooting Service Website

A premium, luxury-styled single-page website for Android Rooting, Custom ROMs, and Software Repair services. 

## Features Included:
- **Dark Mode / Glassmorphism UI**: Inspired by Apple & Nothing design language.
- **GSAP & AOS Animations**: Smooth scroll and reveal effects.
- **Particles.js**: Interactive subtle background hero effect.
- **Fully Responsive**: Built with Bootstrap 5 Grid.
- **SEO Ready**: Proper meta tags implemented.
- **PWA Support**: Basic `manifest.json` included for add-to-homescreen capabilities.
- **Zero Configuration**: Just upload to GitHub pages.

## Deployment to GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and `manifest.json` to the root folder (Or just drag and drop the files from this zip!).
3. Go to **Settings** > **Pages**.
4. Set the source to `main` (or `master`) branch.
5. Save, wait 2 minutes, and your site is live!

*Note: Replace QR code placeholder images inside the Payment section in the HTML file once your site is live.*
